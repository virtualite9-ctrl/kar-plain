# Hermes 통합과 호출 범위

## 적용 대상

Kar-plain은 설명의 표현 형식을 고르는 스킬이다. 자료 수집·메모리 승격·삭제·정본 판정·실행 승인을 대신하지 않는다.

- 글: 정확한 조건과 판단을 읽어야 할 때.
- 도해: 관계·분기·순서를 봐야 할 때.
- 웹: 값을 바꾸며 실험해야 할 때.
- 영상: 시간에 따른 변화를 봐야 할 때.
- 자동: 가장 작은 유효한 형식 하나를 고른다.

한국어를 선호하는 사용자에게는 한국어 설명을 쓴다. 사용자가 영어 출력을 지정하면 영어로 쓴다. 인용문이 영어라고 출력 언어를 영어로 바꾸지 않는다.

## 호출

- `kar-plain 글: 이 보고서의 확인 사항과 남은 작업을 설명해 줘.`
- `kar-plain 도해: 제안과 실제 적용 사이의 승인 경계를 보여 줘.`
- `kar-plain 웹: 조건을 바꾸며 결과를 살펴볼 HTML을 만들어 줘.`
- `kar-plain 영상: 이 과정을 자막 있는 영상으로 설명해 줘.`

Hermes에서는 스킬 선택 후 실제 본문이 로드되어야 한다. Codex의 `$kar-plain` 표기나 `agents/openai.yaml`을 Hermes의 전역 설정으로 바꾸지 않는다.

## 야간 메모리 보고서의 표현

새 보고서를 쓰는 워크플로가 이 스킬을 명시적으로 참조할 수 있다. 기존 보고서와 원본 노트를 소급해서 다시 쓰지 않는다.

사람이 읽는 부분은 다음 순서가 적합하다.
1. 이번 실행에서 실제로 확인한 일.
2. 검토 대상·후보·제안·이월 수의 각각 다른 의미.
3. 아직 검증되지 않은 내용과 사람이 결정할 일.
4. 상세 보고서와 검증 원장의 위치.

`completed_verified`는 해당 실행·산출물 검증 상태다. 모든 제안의 내용이 사실로 확정됐거나 원본 노트에 적용됐다는 뜻이 아니다. ‘변경된 노트 수’와 ‘이번 작업이 실제로 수정한 노트 수’를 혼동하지 않는다.

예시 데이터: 검토 대상 7개, 후보 2개, 제안 2개, 이월 0개, 실제 원본 수정 0개.

> 실행과 보고서 저장을 확인했습니다. 노트 7개를 검토하고 제안 2건을 남겼습니다. 원본 노트는 수정하지 않았습니다. 내용의 승격·적용은 별도 검토가 필요합니다.

이 예시는 표현 방식의 합성 사례이며 실제 실행 수치가 아니다. 운영 수치는 해당 원장에서 읽어야 한다.

## 변경하지 않는 것

- 기계 JSON 키, `PROPOSAL_ONLY`, `completed_verified` 등의 상태 식별자.
- 보호 대상 노트의 접근 경계, 로컬 모델 경로와 외부 전송 승인.
- 원문·인용·법률 문언·충실한 번역·수치·조건·부정·불확실성.
- 해시, 모델 검토와 인간 승인의 구분, 검증 후 상태 확정 순서.
- cron 일정, 기존 스캔 범위, 후보 선정·비판·승격 로직.

## 범위와 한계

설치는 글 모드와 구조·보안·발견 경로를 확인하는 작업이다. 도해·웹·영상 생성의 실제 성공을 자동으로 증명하지 않는다. 의미 보존은 지침이며 모든 문장을 검사하는 결정론적 검증기가 포함된 것은 아니다. 영어 기술문에 표준을 참고하더라도 검증되지 않은 ASD-STE100 준수 인증을 주장하지 않는다.
